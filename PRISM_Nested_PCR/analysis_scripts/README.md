PRISM Downstream NGS Analysis & Reporting Pipeline

This directory contains the downstream Python analyses of the Nested PCR data.

These scripts parse genomic alignments to identify on-target integration events, determine reading frames, creates summary tables, and generates graphs.

## Executing the scripts

### Step 1: clean_Bowtie_alignments.py
<br>
This script parses a position-sorted BAM file (Nterm_mapped_clean.csv or Cterm_mapped_clean.csv) using pysam. <br>
It filters out unmapped or quality-failed reads, computes exact 5' and 3' genomic mapping endpoints based on strand orientation, and categorizes each alignment status (proper_pairs, forward_only, or reverse_only). <br>
<br>
Command line: python3 clean_Bowtie_alignments.py <path_to_sorted_bam> <Tagging Terminus (Nterm or Cterm)> <br>
Example: python3 clean_Bowtie_alignments.py Nterm_sorted.bam Nterm <br>
<br>
Output: Generates a structured file named _mapped_clean.csv inside the ../results/ directory.

### Step 2: check_on_target.py
<br>
This script validates whether integrations occurred at intended target sites. It calculates the expected Cas9 cut site (3 bp upstream of the PAM) from an sgRNA library table and matches it to read positions using an asymmetric nearest-neighbor merge (a strict ±50 bp tolerance for junction-defining forward reads, and a broader ±1000 bp window for sheared reverse reads). It further computes precise nucleotide/amino acid shifts relative to coding sequences (CDS) to evaluate frame preservation. <br>
<br>
python3 check_on_target.py <clean_alignments_csv> <sgRNA_library_tsv> <gene_table_tsv> <br>
Example: python3 check_on_target.py ../Nterm/Nterm_mapped_clean.csv ../../common_data/NTERM-LIBRARY-TABLE.tsv Human_Genome_hg38/hg38.gene_table.tsv Nterm <br>
<br>
Output: Generates a table named [Terminus]_annotated_onTarget.csv inside ../results/.
<br>
  
### Step 3: generate_report.py
<br>
This script uses the on-target CSV to compile statistics and graphs. It extracts a list of all successfully tagged genes and makes two graphs: a pie chart on correct donor insertion and a histogram of the distribution of amino acid gains or losses across integrants that are in-frame. <br>
<br>
python3 generate_report.py <annotated_on_target_csv> <br>
Example: python3 generate_report.py ./Nterm/results/Nterm_annotated_onTarget.csv Nterm <br>
<br>
Writes three files to the parent directory of the input CSV:<br>
* _detected_genes.txt (Line-separated text list of unique genes)
* _Profile_PieChart.png
* _AA_Change_Distribution.png


### Step 4: combine_gene_lists.py
<br>
This scripts combines the unique line-separated text files generated by generate_report.py for both tagging orientations.
<br>
python3 combine_gene_lists.py <Nterm_list.txt> <Cterm_list.txt> <output_csv_path> <br>
Example: python3 combine_gene_lists.py ../results/Nterm/Nterm_detected_genes.txt ../results/Cterm/Cterm_detected_genes.txt ../results/Combined.csv <br>
<br>
* Output: A csv file containing genes tagged in N or C terminal (N_terminal_Only, C_terminal_Only), genes that are tagged in at least one terminus, and genes tagges in both termini. <br>
